# Original Source Preservation

The four files in `originals/` are exact, unedited copies of the owner's local Urban Game teaching folder. Each SHA-256 matches the corresponding previously recovered source checksum. `checksums.json` records file lengths, SHA-256 hashes, and Git blob identities.

- `Urban-Game.html`: the complete portable browser game, including its embedded code, source slide text, and visual assets.
- `NCH Copy of Urban Game for World History.pptx`: the original full classroom deck.
- `NCH Copy of Urban Game Rounds 1-10.pptx`: the original shorter classroom deck.
- `Urban Game Board.pdf`: the original board and reflection questions.

The editable 54-entry project package, its ZIP archives, separate asset PNGs, tests, and sample save were not present in this supplied folder. This snapshot does not claim to contain that missing package. The portable HTML is complete and retains the recovered game unchanged.

The existing root README and initial repository history are retained. The `.gitattributes` rule disables newline normalization for all preserved originals. Do not edit or regenerate these originals; any later adaptation belongs in a separate location and commit.

Before upload, the source HTML and document text/metadata were reviewed for credentials and student personal data. No such data was identified. Both PowerPoint ZIP containers pass integrity checks, contain no comments, embedded documents, or macros, and the PDF contains no forms or attachments. This is a scoped source review, not a claim of an exhaustive security audit.
